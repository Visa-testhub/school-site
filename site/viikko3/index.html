1. Commands used

Date command displays the current date, time and time zone. 

date '+%Y-%m-%d %H:%M:%S %Z %z'

df command displays disk usage for the root (/). Its output is piped to awk, which extracts the usage percentage from the second row and fifth column. 

df -P / | awk 'NR==2 {print $5}'

The free command displays system memory information. The -m option shows memory values in MiB. The script uses these values to determine total and available RAM. 

free -m

2. How the script works

A Bash script collects system information using different linux commands like date, uptime and df. Command substitution ($(...)) stores the results in Bash variables.

The script then generates a JSON file containing the collected information. JavaScript on this webpage fetches the JSON file and displays the values.

Disk space status is determined using a function containing an if statement. When disk usage is below 80%, the status is OK. At 80% or above, the status changes to WARNING.

3. Automatic scheduling

Cron is used to execute the Bash script automatically every minute. The crontab schedule uses five asterisks, meaning every minute of every hour and day. 

* * * * *

Each execution generates an updated JSON report. The website reads the latest data from that file. The cron configuration is stored in the user's crontab and persists across system reboots, provided the cron service is running.

4. A problem encountered

While developing the Bash script using Visual Studio, the script produced error "command not found" for carriage return characters.

The problem was caused by Windows line endings, while the Bash script expected Unix-style LF line endings.

I solved the issue by removing the carriage return characters from the file using sed and changing the file's line ending format to Unix. 

sed -i 's/\r$//' generate-system-status.sh

Questions & answers

1. Linux distribution and version

I'm using Ubuntu 26.04.1 LTS. This can be verified using 

cat /etc/os-release

2. What is Nginx, and what does it do in this server?

Nginx is a web server software that receives HTTP requests and sends responses back to them.

It's designed to efficiently handle many simultaneous connections.

Nginx can also serve as reverse proxy, load balancer and for caching and HTTPS encryption.

On this server, Nginx listens for incoming requests on port 80 and serves the requested HTML and CSS files from /var/www/school-site/.

3. Which commands did I use?

To start. I refreshed the package lists with 

sudo apt update

Then I updated the updatable packages with 

sudo apt upgrade

Next I installed engine x with 

sudo apt install nginx

And after that I checked if it was enabled to start up with 

systemctl is-enabled nginx

If it would have not been enabled I would have enabled it with 

sudo systemctl enable nginx

Enabling is basically is enabled at startup. So if server reboots, the nginx is restarted

Next part is completely optional btw and doesn't affect the nginx working on any way. It's just some customisability on how the terminal looks.

Next I needed to change how the command line looks on the server, so I installed command line shell and Oh My Szh. Oh My Zsh is a framework that provides themes, plugins and configuration to Zsh. I also wanted autosuggestions so I got it as well Next are the commands to get both. 

sudo apt install zsh git curl
sh -c "$(curl -fsSL https://raw.githubusercontent.com/ohmyzsh/ohmyzsh/master/tools/install.sh)"
git clone https://github.com/zsh-users/zsh-autosuggestions ${ZSH_CUSTOM:-~/.oh-my-zsh/custom}/plugins/zsh-autosuggestions

Then the zsh configurations have to be modified with i.e. nano. the config file is in ~/.zshrc there you have to add autosuggestions along the git in to plugins=(git) like this plugins=(git zsh-autosuggestions) Next you can save and reload with 

source ~/.zshrc

If all is succesful, you should have autosuggestions to commands you have already done once. Then you can change your default shell with 

"command">sudo chsh -s "$(command -v zsh)" "$USER"
